# 00 — Zanim dotkniesz czegokolwiek

> **Część I** · **Oznaczenia:** 🟢🏠📋 · **Ścieżki:** SEP, dom · **Szacowany czas:** ok. 3 h · **Status:** 🔲 szkielet

## Po co ten moduł

Zasady, które chronią życie przy każdej pracy w tym repozytorium — od wymiany gniazdka po pomiary. Ten moduł czyta się pierwszy i wraca do niego przed każdą pracą praktyczną.

## Wymagane wcześniej

brak — od tego modułu można zacząć.

## Zakres egzaminu SEP

- **(c)** obsługa, konserwacja, remont, naprawa, montaż, demontaż, czynności kontrolno-pomiarowe
- **(d)** BHP, ochrona przeciwpożarowa, pierwsza pomoc
