## Po tym module potrafisz

- podłączyć gniazdo z bolcem i gniazdo siłowe oraz sprawdzić je po montażu,
- rozpoznać i podłączyć łączniki 1, 2, 5, 6, 7 i wyjaśnić, dlaczego łącznik przerywa fazę,
- dobrać puszkę i zaplanować połączenia tak, żeby pozostały dostępne,
- wybrać złączkę do przewodu i wyjaśnić, dlaczego skrętka nie jest połączeniem,
- odczytać kod IP i dobrać stopień ochrony do miejsca montażu,
- rozpoznać klasy ochronności 0, I, II, III i wiedzieć, które urządzenia potrzebują PE.
