## Po tym module potrafisz

- wyjaśnić, czego przeciążenie i zwarcie wymagają od zabezpieczenia, i policzyć prąd zwarcia z impedancji pętli,
- rozpoznać wkładki D, D0, NH, odczytać ich prąd i klasę gG/aM i wymienić je bezpiecznie,
- opisać budowę wyłącznika nadprądowego i odczytać oznaczenia na jego froncie,
- dobrać charakterystykę B, C lub D i sprawdzić jej wpływ na impedancję pętli,
- sprawdzić, czy zdolność zwarciowa aparatu wystarcza w miejscu montażu,
- dobrać zabezpieczenie do przewodu (IB ≤ In ≤ Iz, I2 ≤ 1,45 Iz) i ocenić selektywność.
