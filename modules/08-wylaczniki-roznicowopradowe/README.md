# 08 — Wyłączniki różnicowoprądowe

> **Część II** · **Oznaczenia:** 🏠📋 · **Ścieżki:** SEP, dom · **Szacowany czas:** ok. 6 h · **Status:** ✅ pełny

## Po co ten moduł

Różnicówka to najważniejsze urządzenie ratujące życie w domowej instalacji. Moduł wyjaśnia, jak „liczy” prąd, który typ wybrać i dlaczego wybija.

## Po tym module potrafisz

- wyjaśnić zasadę działania RCD i wymienić, przed czym nie chroni,
- dobrać IΔn do celu: ochrona uzupełniająca, przy uszkodzeniu, przeciwpożarowa,
- dobrać typ AC, A, F lub B do odbiorników,
- rozpoznać i podłączyć RCBO,
- użyć przycisku TEST i wiedzieć, co sprawdza pomiar miernikiem,
- metodycznie szukać przyczyny wybijania różnicówki,
- podzielić obwody mieszkania między RCD i zapewnić selektywność.
