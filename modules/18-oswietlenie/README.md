## Po tym module potrafisz

- czytać opakowanie LED (lm, K, Ra) i dobrać zasilacz CV lub CC,
- podłączyć łącznik jednobiegunowy i świecznikowy,
- zmontować układ schodowy i krzyżowy, także „w puszkach”,
- zastąpić łańcuch łączników przekaźnikiem impulsowym z przyciskami,
- dobrać ściemniacz do LED (RL/RC, moc minimalna),
- zasilić taśmę LED bez spadku jasności i przegrzewania.
