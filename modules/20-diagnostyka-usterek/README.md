# 20 — Diagnostyka usterek

> **Część IV** · **Oznaczenia:** 🏠📋 · **Ścieżki:** SEP, dom · **Szacowany czas:** ok. 5 h · **Status:** 🔲 szkielet

## Po co ten moduł

Systematyczne szukanie usterek zamiast zgadywania — drzewka decyzyjne dla najczęstszych objawów, w tym groźnej przerwy w przewodzie neutralnym.
