## Po tym module potrafisz

- dobrać przyrząd i przewody do kategorii pomiarowej miejsca pomiaru,
- mierzyć multimetrem napięcie, prąd i rezystancję bez ryzyka zwarcia,
- mierzyć prąd i upływ cęgami,
- wybrać właściwy przyrząd do sprawdzenia braku napięcia,
- opisać funkcje miernika parametrów instalacji i wymagania PN-EN 61557,
- ocenić termogram połączenia metodą ΔT.
