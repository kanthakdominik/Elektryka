## Po tym module potrafisz

- opisać poziomy napięć w systemie, budowę i pracę sieci SN (pętla z punktem podziału, punkt neutralny),
- wymienić elementy stacji SN/nN i rodzaje stacji, wyjaśnić grupę Dyn5,
- odróżnić odłącznik, rozłącznik, wyłącznik i uziemnik oraz podać kolejność łączeń,
- wyjaśnić ochronę przeciwporażeniową powyżej 1 kV: osłony, odstępy, uziemienia, napięcia dotykowe zależne od czasu,
- podać odstępy DL/DV dla 3–30 kV i kolejność przygotowania pracy przy wyłączonej linii SN.
